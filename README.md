# Quran Companion

Static GitHub-ready starter.

## Run
Open `index.html` directly, or deploy the repository with GitHub Pages.

## Included
- Calm responsive UI
- Light/dark mode
- Ayah of Day/Week/Month
- Quran entry point
- 114 Surah list from a Quran data API
- Complete selected-Surah Ayah display (Arabic + English)

## Next production integrations
Audio/reciters, vetted Roman-English/transliteration, tafsir, Quran AI, hadith verification, prayer/Qibla, privacy/account sync, and mobile apps.
